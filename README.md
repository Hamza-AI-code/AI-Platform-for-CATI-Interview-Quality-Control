# 📖 Overview

AI CATI Quality Platform is an intelligent quality assurance solution developed for market research organizations conducting Computer-Assisted Telephone Interviewing (CATI).

The platform automatically evaluates completed interviews by comparing the original survey questionnaire, interviewer responses, and call transcripts. Using both deterministic validation rules and AI-powered semantic analysis, it identifies inconsistencies, skipped questions, routing errors, suspicious interviewer behavior, fabricated interviews, and response contradictions.

Unlike traditional cloud-based AI solutions, the entire reasoning process runs locally using **Ollama**, ensuring complete privacy without requiring external APIs or cloud services.
